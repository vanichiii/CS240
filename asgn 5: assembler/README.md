# MIPS Assembler and Disassembler

This program uses Java to assemble MIPS code into binary, both in ascii format and raw binary format.

## Assembler
Use terminal to execute program
1. Compile the program (javac Assembler.java)
2. Run the program (java Assembler)
3. Review that fizzbuzz.mhc-ascii and fizzbuzz.mhc-bin have been created inside the program folder

## Disassembler
Use terminal to execute program
1. Compile the program (javac Disassembler.java)
2. Run the program (java Disassembler [insert .mhc-bin or .mhc-ascii] [name your new file (.asm)]
3. Ensure that new .asm file has been created and is located inside the program folder.

Most errors have been taken into account for this program. Test results are inside of the PDF submitted into canva.
